Features

Small app. Serious control.

Everything scrcpy can do — wrapped in an interface anyone can use.

🚀

One-Click Mirroring

Connect your device and press Mirror. BasicMirror builds the right scrcpy command for you — no terminal, no flags to memorize.

📱

Multi-Device

Mirror several phones at once via USB or WiFi, and save them as named device profiles for next time.

📶

USB → WiFi

Open a WiFi port once, unplug the cable, and keep mirroring wirelessly over your network.

🎬

Screen Recording

Start / stop controls with MP4 and MKV output and a custom save path, right from the main window.

📥

Auto scrcpy Download

On first launch, scrcpy is fetched straight from Genymobile's official repository — binaries are never re-hosted.

⚡

Lightweight & Portable

A single ~50 KB exe. No installer, no dependencies beyond .NET Framework 4.8, which ships with Windows 10+.

Quick start

Zero to mirrored in three steps

Under a minute, start to finish.

01

Download the exe

Grab BasicMirror.exe from GitHub Releases — one ~50 KB portable file, nothing to install.

02

Let it fetch scrcpy

On first launch it downloads scrcpy (~15 MB) directly from the official Genymobile repository.

03

Connect & mirror

Enable USB debugging, plug in your phone, hit Refresh → Mirror. Done.

Under the hood

Every scrcpy flag, one toggle away

BasicMirror maps scrcpy's most useful options to simple dropdowns and checkboxes — the same flags power users type by hand.

--max-size · --max-fps · --video-bit-ratefull quality control
